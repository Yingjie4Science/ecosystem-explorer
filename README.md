# Urban Ecosystem Explorer dashboard

This folder contains the interactive dashboard demonstration for Chinese cities. All city outputs are synthetic and are not official statistics or calibrated model results.

## Run on this Mac

Double-click `start-local.command`, then open [http://127.0.0.1:4173/](http://127.0.0.1:4173/) in a browser. Keep the Terminal window open while using the dashboard.

## Included workflow

- Select Shenzhen, Chengdu, Beijing, or Shanghai and a demonstration subregion.
- Explore each focal city on an interactive OpenStreetMap basemap, with a China overview inset.
- Set developed-land conversion, placement priority, land allocation, and eligibility constraints.
- Review cooling, runoff retention, nature access, carbon, feasibility, and secondary benefit indicators.
- Compare up to four scenarios and export the current scenario as a JSON record.
- Review evidence status and the intended handoff to a canonical InVEST workflow.

The basemap and city locations are factual OpenStreetMap data. Colored priority zones and all modeled outputs remain synthetic demonstration content. An internet connection is required to load map tiles.
